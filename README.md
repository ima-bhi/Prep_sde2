# SDE-2 Prep Handbook

A 12-week plan for preparing for SDE-2 backend (Node.js) interviews, as a single HTML page.

- **DSA:** NeetCode 150, with CodeStoryWithMIK when stuck
- **HLD:** Hello Interview, Jordan has no life, ByteByteGo, DDIA
- **LLD:** Concept && Coding (Shrayansh Jain), Refactoring Guru
- **Backend track:** Node.js internals, PostgreSQL, MongoDB, Redis, Kafka, resilience patterns
- **Behavioral:** a STAR story bank, then mock interviews in weeks 11–12

## How to use it

Open `index.html` in any browser. You can double-click it, since it needs no build step or server.

- Set your start date at the top. Week dates and the current week update from it.
- Tick off tasks, count NeetCode problems per category, and draft STAR stories.
- Open topics from **Prerequisites** at the top. Each one is a notes page in the `notes/` folder. To add a topic, save its page in `notes/` and add an entry to the `PREREQS` list in `index.html`.
- Progress is saved in your browser's localStorage. Click **Export progress** to download a JSON backup, and **Import progress** to restore it on another computer or browser.
